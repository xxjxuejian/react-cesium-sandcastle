# 杭州边界分层页面

路由：`/hangzhou/boundaries`。此页独立于原来的 `/hangzhou/regions`，用于验证同一套区县几何派生出的双色边界。

与 `regions` 逐区县绘制完整环线的方式相比，本页使用预先分类、去重的线数据，分别绘制金色全市外缘和红色内部区界，共享线段只画一次。拾取只关联区县面和标签；本页还增加了区县下钻与返回。完整对比和建议学习顺序见 [`regions` 页面说明中的“与 boundaries 页面的区别”](../regions/README.md#与-boundaries-页面的区别)。

- `hangzhou.wgs84.geojson`：只取 13 个区县面，显示贴地填充和名称标签；独立市级面不参与绘制。
- `hangzhou.boundaries.wgs84.geojson`：`outer` 绘制金色全市外缘，`inner` 绘制红色区县共享界线。每条派生线只绘制一次，不再循环绘制区县完整环线。
- 区县面和标签保留悬停高亮、点击选中；共享区界对应两个区县，暂不自动选中任意一侧。点击界线会清除当前选中状态。
- 选中区县后可在详情面板点击“进入区县”；相机按该区县完整面几何的范围飞入，而不是只飞向标签点。面包屑显示“杭州市 / 区县”，点击“杭州市”返回全市，清除选中状态但保留边界和标签。
- 两份数据同时请求；页面卸载时终止请求并清理 DataSource、折线、标签、事件处理器和相机飞行。

双色边界的首次浏览器核对由用户反馈“基本没发现问题”；这不等于测绘精度或原始坐标系得到证明。
