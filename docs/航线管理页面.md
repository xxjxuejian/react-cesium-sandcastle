# 航线管理页面

## 页面入口与代码位置

页面沿用已有 `/system-management/airline-management` 路由，菜单名称为“航线管理”。新增、查看和编辑在当前路由内切换工作区，返回时保留列表的搜索条件和页码。

列表布局与用户管理页一致：顶部为行内查询表单，下方独立一行右对齐放置“新增航线”按钮，再下方展示表格及分页。列表不额外显示页面标题和说明文本。

航线列表高度限定在当前视口内，表格数据区独立滚动，查询区、新增按钮、表头和底部分页不随数据滚动。`ResizeObserver` 根据表格剩余空间和实际表头高度计算 `scroll.y`，窗口缩放或查询区域换行时自动调整。分页独立放在滚动区外；该调整不改变其他页面或航线编辑工作区的滚动方式。

列表高度根据页面实际顶部位置、视口高度和两层底部内边距计算，不写死顶部栏高度；翻页或重新查询后将表格数据区滚回顶部。

| 文件 | 职责 |
| --- | --- |
| `src/pages/system-management/airline-management/index.tsx` | 列表、搜索分页、详情请求、保存与删除，以及工作区切换 |
| `src/pages/system-management/airline-management/AirlineEditor.tsx` | 基本信息、航点表单、排序、批量高度、保存前校验及未保存返回确认 |
| `src/pages/system-management/airline-management/AirlineMap.tsx` | 页面专属的二维路径、航点选择与拖动、相机定位和 Cesium 资源清理 |

拆分编辑区和地图是为了将表单状态与 Cesium 生命周期分开阅读，不增加页面专属自定义 Hook，也不修改通用 `CesiumMap`。

## 从打开页面到保存的执行流程

1. 页面调用 `getAirlineList()`，列表只使用 `AirlineListItem` 摘要，不提前加载全部航点。
2. 输入搜索文本后，点击搜索或按回车才更新查询条件。搜索从第 1 页开始，支持重置、刷新和调整每页数量。
3. 点击查看或编辑时，调用 `getAirlineDetail(id)`。请求成功后，编辑区通过 `initialValues` 初始化基本信息和航点；不同记录使用不同的组件 `key`，避免串用表单数据。
4. `Form` 保存未提交的航点。`Form.useWatch` 订阅航点变化，更新数量、水平长度及地图路径，地图不另存一份航点。
5. 地图添加和拖动通过回调修改表单；表单输入、上移、下移、删除和批量高度也修改同一份数据。数组顺序就是航点顺序，保存时由接口重新生成 `order`。
6. 点击结束绘制只切换绘制状态。点击保存后，页面校验名称、速度、航点数量、坐标、高度及相邻重复点，再一次调用新增或更新接口。
7. 保存成功返回列表并刷新；保存失败保留输入并显示接口错误。删除需要确认，删除末页最后一条时回到前一页。

返回列表时，有修改则先确认是否放弃；浏览器刷新或关闭前也会提示。直接切换侧边栏路由仍会离开当前编辑区，未保存数据不会持久化。

## 编辑与地图操作

- 左侧基本信息包含名称、统一飞行速度和备注，不增加所属场地或航线统一高度。
- 点击开始绘制，在地图上依次添加航点；结束后可以继续添加。
- 绘制时点击已有航点会选中它；需要同一经纬度的垂直升降航段时，可手动添加航点并分别设置高度。
- 点击地图航点会选中并滚动到对应列表行；点击航点行或标题会定位地图。
- 结束绘制后，按住地图航点拖动可以修改经纬度，高度保持不变。
- 拖动期间暂停相机输入，松开、取消拖动或窗口失去焦点时恢复；拖动结束不会额外新增航点。
- 批量高度同时用作后续地图新增航点的默认高度，初始为 60 米；只写入各航点，不保存独立统一高度字段。
- 输入坐标暂时为空或无效时，不将该值交给 Cesium，也不跨过无效航点连接路径。
- 查看复用同一工作区，所有编辑、绘制、排序和删除入口禁用或隐藏，仍可定位航点和预览整条航线。

## 地图与高度基准

新增、查看和编辑共用 `AirlineMap`，使用 Cesium 二维地图，通过公共 `useBasemap("tianditu")` 与 `MapToolbar` 提供底图切换。默认天地图矢量底图（`vec_w`）与中文注记（`cva_w`），可在“底图”面板切为天地图影像（`img_w`＋`cia_w`），也可切为 OSM。工具栏只启用 `tools={["basemap"]}`，不调用测量 Hook，因此不增加测量取点事件。

沿用项目已有的 `VITE_TIANDITU_TOKEN`，本地在 `.env.local` 配置，修改后重启 `pnpm dev`；变量示例见根目录 `.env.example`，实际 Key 不写入源码或文档。未配置 Key 时初始使用 OSM，底图面板禁用天地图并提示配置 Key。错误提示与重试由公共工具负责，坐标和高度仍可以通过表单编辑。切换时仅替换工具创建的图层，相机视角、航点与未保存表单保持不变；离开工作区时公共 Hook 清理图层和错误监听器。

地图只显示 WGS84 水平路径，航点标签显示序号及相对高度，不把“相对本次起飞点高度”当成 Cesium 椭球绝对高度。不自动闭合路径，不校验场地范围或圈层，不包含飞行执行。

后续如果需要三维高度预览，应先明确本次起飞点及其绝对高度，再统一转换，不能直接将航点的 `altitude` 传成绝对海拔。
