# 后端分阶段实施任务

更新日期：2026-11-07。依据前端现有页面、API、Mock、类型定义及《Node.js 后端入门规划》划分。

本文记录实施阶段和验收情况。阶段编号以本文为准，原规划描述整体设计。

业务表按模块逐步增加：阶段 1 建 users、sessions，阶段 4 建 shelters，阶段 5 建 airlines，阶段 6 建 key_units。迁移记录表属于技术辅助表，不计入规划的五张业务表。

## 二、阶段 0：基础骨架，已完成

后端目录为前端同级的 `react-cesium-server/`。已具备 Express、TypeScript、pnpm、独立 Git 仓库、开发热重载、生产构建、中文 README 和协作约定。

现有 `src/server.ts` 负责监听端口，`src/app.ts` 定义接口与错误响应。已有健康检查，以及 JSON 404、400、413 和 500 处理。

阶段 0 验收时已通过 lint、typecheck、4 项 HTTP 测试、build，并实际验证 dev/start 启动。当时尚未接入数据库、登录和管理接口；后续阶段已逐步补齐。健康检查本身不作为数据库就绪证明。

阶段 2 联调步骤：

1. 在独立后端初始化数据库和管理员，再运行 `pnpm dev`。管理员使用自己在后端初始化时设置的用户名和密码。
2. 在前端仓库 `react-cesium-sandcastle/` 的 `frontend_single` 分支运行 `pnpm dev`，访问终端显示的地址。`frontend_single` 是分支名。Vite 会将 `/api` 转发到 `http://127.0.0.1:3000`。后端端口不同时，在前端 `.env.local` 设置 `VITE_API_PROXY_TARGET`。
3. 本分支没有模式切换。浏览器继续使用 `app-real-access-token` 保存真实会话凭证。

阶段 2 完成时，管理员与普通用户在真实模式下都只访问已开放的示例页面。阶段 3 已为管理员开放用户管理；其余管理页面随业务模块上线逐个开放。管理员接口通过会话校验和管理员校验两道中间件限制访问。
