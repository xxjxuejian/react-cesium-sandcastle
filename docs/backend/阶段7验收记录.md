## 五、限制与部署前仍需完成的验证

- 本轮没有发布到服务器，未实际配置域名、HTTPS 证书、Nginx、systemd、防火墙或开机恢复。示例需在目标服务器修改并验证；不能把本地代理验收等同于 Nginx 验收。
- 没有在干净机器重新安装全部依赖，也没有在 Node.js 最低版本、Linux 或其他浏览器上重复整套检查。
- 当前后端只部署单实例。Express 未启用 `trust proxy`，经过反向代理的登录请求共享来源限流；多用户部署前需根据可信代理范围单独验证。

- 备份命令按需执行；尚未配置服务器定时备份、异地存储、监控或备份保留策略。数据库已能备份恢复，不等于这些运维配置已完成。
