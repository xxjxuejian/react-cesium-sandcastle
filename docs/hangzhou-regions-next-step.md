# 杭州行政区示例：当前进度与下一步

> 进度同步：2026-10-24。用户已确认 `CES-REGION-006` 完成，并明确 `CES-REGION-007` 不属于 `/hangzhou/boundaries` 页面的实现范围。

## 当前基线

`/hangzhou/regions` 已完成第一轮行政区展示和交互能力：

- 使用 `CesiumMap` 和 Cesium World Terrain 创建三维场景；
- 从 `public/geojson/hangzhou.wgs84.geojson` 中只取 13 个区县绘制，独立市级要素不参与本页渲染；
- 使用贴地 Polygon 显示半透明区县填充；
- 使用独立的贴地 Polyline 显示区县完整环线，当前也包含全市外缘；
- 显示区县名称，页面读取标准数据中的 `labelPoint`；转换脚本在原始 `centroid` 缺失时使用 `center` 生成该点；
- 鼠标移入区县时高亮当前区域，移出后恢复；
- 点击区县后保持选中样式，并显示名称与行政编码；
- 点击地图空白区域取消选择；
- 区县面、名称标签和边界线均可识别到同一个区县；
- 页面卸载时清理请求、DataSource、Entity、事件处理器和相机飞行。

标准面文件由两份原始文件按“原坐标为 GCJ-02”的推定转换而来；新增的 [`hangzhou.boundaries.wgs84.geojson`](../public/geojson/hangzhou.boundaries.wgs84.geojson) 只从区县面派生显示用的外缘与内部区界，未使用独立市级面的坐标。来源和精度限制见 [`public/geojson/README.md`](../public/geojson/README.md)。此前原页面的其他交互功能已经由用户验证；双色边界的首次浏览器核对由用户反馈“基本没发现问题”，区县下钻现已由用户确认完成。

原页面不再保留独立市界的折线绘制代码。区县完整环线已经包含全市外缘；若再叠画独立市界，就会用两套略有差异的坐标重复绘制同一外缘，局部可能出现错开的双线、颜色交错或毛边，调整 `zIndex` 也不能消除坐标差异。原页面统一使用区县数据；需分色且避免共享线重复绘制时使用双色页面的派生边界文件。

## 双色边界新页面

新增 [`/hangzhou/boundaries`](../src/pages/hangzhou/boundaries/README.md) 页面，与只绘制区县完整环线的 `/hangzhou/regions` 分开：

1. 新页面从派生文件绘制金色 `outer` 和红色 `inner`，不再逐区县绘制完整环线，也不启用独立市级面的描边。
2. 内部界线按相邻区县对只有一条线；默认不将共享界线映射到任意一侧区县，区县面和标签仍可高亮、选中。
3. 后续回归时检查外缘与内部区界没有双线、断口，13 个区县面与标签未被遮挡；切换路由后线条能清理。

视觉核对只能用于发现明显偏移，不能作为测绘精度证明。

数据处理已生成 1 条闭合外缘和 27 组相邻区县内部界线。`node --test scripts/hangzhou-boundaries.test.mjs` 已核对每条区县线段恰好分配到外缘或内部区界之一。双色边界首次浏览器核对基本未发现问题，区县下钻现已由用户确认完成。

此前新页面接入及下钻实现后，`pnpm lint` 与 `pnpm build` 均通过；本地预览中的 `/hangzhou/boundaries` 路由及两份 GeoJSON 请求曾返回 HTTP 200。下钻与返回按用户最新确认记录为已完成。

## 已完成：区县下钻与返回

双色边界页面已完成 `CES-REGION-006`，用户已确认完成，功能包括：

1. 在当前区县详情面板中增加“进入区县”操作；
2. 用户触发后，相机飞入当前选中区县；
3. 页面显示“杭州市 / 当前区县”面包屑；
4. 点击“杭州市”返回全市视角；
5. 返回后保留区县边界和标签，并清除下钻选择状态；
6. 离开页面时取消尚未完成的相机飞行，不留下下钻状态。

下钻仍留在当前页面实现，未引入全局 Viewer 或全局行政区状态。相机按所选区县完整面几何的包围矩形取景，并保留少量边距；点击区县仍只选中，不自动飞入。
