# 无人机模拟飞行与告警规划

更新日期：2026-10-31。本文记录尚未实现的后续需求，不代表当前页面已有模拟或告警能力。

已完成的管理页面、字段和校验以[重点单位管理接口](./重点单位管理接口.md)、[航线管理接口](./航线管理接口.md)及[航线管理页面](./航线管理页面.md)为准。原页面设计和综合管理规则中的已实现内容已合并到这些维护文档。

## 已有数据与高度约定

- 重点单位包含一个共同中心，以及核心圈、反制圈、警戒圈；半径严格递增，三个高度区间逐层包含。
- 航线和重点单位独立保存，航点按数组顺序飞行。航线至少两个航点，整条航线使用统一速度，各航点独立保存 `altitude`。
- 地面统一假设为 0 米平面，航点、防御圈和无人机模拟高度直接比较，不叠加单位地面高度或起飞点高度，不采样真实地形。
- 同一水平位置、不同高度的相邻航点允许表达垂直升降；完全重合的相邻航点无效。
- 当前重点单位已有三维防御空间预览；航线地图仍是二维路径，尚无无人机飞行执行。

## 模拟飞行的数据衔接

1. 选择本次使用的重点单位和航线，加载已保存的防御范围及航点。
2. 在同一地图展示两者，全部高度相对统一零平面。
3. 按模拟时间和航段插值规则计算无人机当前位置与高度。
4. 同时判断水平范围与高度区间，显示前端告警。

同一条航线可以搭配不同重点单位，本次选择不形成永久绑定。建议模拟开始时固定本次数据，管理页编辑不直接改变正在执行的模拟；任务如何保存仍待设计。

航线穿过圈层不视为航线无效。飞行前相交预览与飞行中进入告警是不同能力，仅检查航点不足以判断整条航线是否穿过防御空间。

## 告警判断与优先级

设 `d` 为无人机与单位中心的水平距离，`h` 为相对统一零平面的高度。命中某圈须同时满足：

```text
d ≤ 本圈半径
本圈最低高度 ≤ h ≤ 本圈最高高度
```

建议水平边界和上下高度边界均计入圈内。俯视位置在圆内，但高度超出本圈区间时，不命中该圈。距离计算与地图边界应使用一致的地理计算口径，不能用含高度差的三维直线距离或屏幕像素代替。

无人机可能在两次更新之间穿入又穿出一个圈，不能只检查稀疏采样点；具体采用航段穿越检测或其他可靠策略，需在模拟模块设计时确定。

建议保留全部命中圈层，主要提示只展示最高优先级：核心圈 > 反制圈 > 警戒圈。由于空间逐层包含，命中核心圈也会命中其外两层，不为同一位置同时弹出三个告警。

| 无人机所在空间 | 主要状态 |
| --- | --- |
| 不命中警戒空间 | 无圈层告警 |
| 命中警戒空间，不命中反制空间 | 警戒圈告警 |
| 命中反制空间，不命中核心空间 | 反制圈告警 |
| 命中核心空间 | 核心圈告警 |

“反制圈”仅为区域名称，不代表系统自动执行反制动作。

## 状态变化与记录

- 从无告警进入任一圈时提示一次，并保持当前主要状态。
- 最高优先级变化时更新提示，持续同一状态不逐帧重复弹窗。
- 退出内层但仍命中外层时降级，离开全部防御空间时解除告警；水平或高度变化均可能导致状态改变。
- 模拟开始时若已经命中防御空间，立即显示对应状态。
- 缺少有效位置或高度时显示数据异常或暂停判断，不能显示“无告警”来代表判断成功。

告警记录应归属模拟任务，包含单位标识、圈层类型、时间、无人机位置与高度及状态变化，不作为单位或航线的静态属性。

防御圈告警表示进入需要关注的空间；越界报警表示离开允许飞行的空间。警戒圈不自动成为允许飞行边界。当前没有独立允许飞行范围，如需越界报警，须另行确定规则。
